# Santosh Kumar Shaw — academic website

A static, five-page site. No build step, no framework, no dependencies. Plain HTML and
one stylesheet, so it works on GitHub Pages as-is.

```
index.html          Home — research overview
publications.html   Publications
code.html           Code / repositories
teaching.html       Teaching assistantship
contact.html        Contact and office address
style.css           All styling
assets/             Hero graphic, placeholder, small JS
images/             Your figures (see images/README.md)
```

## 1. Put it online

1. Go to GitHub and create a **new empty repository** named exactly `SKS-CP.github.io`.
   Do not add a README, .gitignore or licence — leave it empty.
2. Open a terminal in this folder (the one containing `index.html`).
3. Run these commands one at a time:
   ```bash
   git init
   git add .
   git commit -m "Initial site"
   git branch -M main
   git remote add origin https://github.com/SKS-CP/SKS-CP.github.io.git
   git push -u origin main
   ```
4. On GitHub, open the repository → **Settings** → **Pages**.
5. Under "Build and deployment", set Source to **Deploy from a branch**, branch **main**,
   folder **/ (root)**, then click **Save**.
6. Wait about a minute, then open **https://SKS-CP.github.io** — the site is live.

If you would rather keep the repository under a different name, for example `website`,
everything above still works; the address becomes
`https://SKS-CP.github.io/website/` instead.

## 2. Add your figures

1. Download each image from your Google Site (right-click → Save image as).
2. Rename them to the filenames listed in `images/README.md`.
3. Drop them into the `images/` folder.
4. Commit and push:
   ```bash
   git add images
   git commit -m "Add figures"
   git push
   ```

Until an image is added, a dashed "FIGURE" placeholder shows in its place, so the page
never looks broken.

## 3. Update the site later

1. Edit the relevant `.html` file in any text editor. The content is plain HTML — the
   text you want to change is visible in the middle of the file.
2. To add a publication, copy one `<li>` block in `publications.html` and change the
   title, link and DOI. The numbering is automatic.
3. To add a course, copy one `<li>` line in `teaching.html`.
4. Save, then run:
   ```bash
   git add .
   git commit -m "Update publications"
   git push
   ```
5. The live site updates within a minute or so.

## 4. Point your own domain at it (optional)

1. Buy a domain, for example `santoshshaw.in`.
2. At your domain registrar, add four A records pointing to `185.199.108.153`,
   `185.199.109.153`, `185.199.110.153` and `185.199.111.153`.
3. In the repository, Settings → Pages → Custom domain, enter the domain and save.
4. Tick **Enforce HTTPS** once the certificate is issued (this can take a few hours).

## Notes

- `assets/lattice.svg` is the animated edge-dislocation graphic on the home page. It was
  generated by `assets/make_lattice.py`; you only need that script if you want to change
  the lattice.
- `assets/build_pages.py` regenerates the four inner pages from a shared template so the
  navigation stays identical across them. If you edit the inner pages by hand, do not run
  it again — it will overwrite your edits.
- Both scripts can be deleted if you prefer to maintain the HTML by hand.
